Methodology

Each commit is checked out, the frozen #1067 benchmark harness is overlaid (so only the library implementation varies), and the suite is built and run with a single fixed Go toolchain. Numbers are the median of the samples. macOS and Linux are different machines — compare each series against itself, never across platforms. Commits before the suite's required API existed (e.g. Decoder.DisallowUnknownFields) do not build and are reported as skipped.
