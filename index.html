Methodology & caveats

The benchmark harness is held constant (frozen #1067 suite overlaid on each commit) so only the library implementation varies; each commit is built and run with one fixed Go toolchain. macOS and Linux are different machines — read each series against itself, not across platforms. The x-axis is commit order on v2 (committer dates are non-monotonic from rebases). Commits whose API predates the suite (e.g. DisallowUnknownFields) do not build and are omitted.
